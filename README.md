# Contacts

Application Android (Kotlin) de gestion d'une liste de contacts.

## Fonctionnalités
- Affichage de la liste des contacts, avec sélection d'un contact
- Ajout d'un contact (message de confirmation)
- Modification du contact sélectionné
- Refus des doublons (« Ce contact existe déjà dans la liste »)
- Suppression avec boîte de dialogue de confirmation

## Technologies
Kotlin, ViewModel (ContactsViewModel), Material Components

## Lancer le projet
Ouvrir dans Android Studio, synchroniser Gradle, lancer sur un émulateur.
